updates and references must be resolved before an alert is considered active.

## Parser rules derived from the observation

The CAP parser now:

- requires the CAP 1.2 namespace,
- uses a parser with external entities disabled,
- preserves alert identifiers, references, update and cancellation semantics,
- converts all timestamps to UTC and rejects timestamps without a timezone,
- keeps the original German official texts separate from local decisions,
- validates polygons as closed non-self-invalid rings,
- parses CAP circles as latitude, longitude and radius in kilometres,
- evaluates direct geometry before any geocode fallback,
- returns `UNKNOWN` when an area contains only unresolved geocodes,
- ignores expired, non-public, non-actual and cancellation messages for display,
- never interprets an empty or failed CAP source as "no warnings".

## ZIP safety rules

The archive layer:

- accepts only `.xml` files,
- rejects absolute, parent and drive-like paths,
- rejects symlinks and encrypted members,
- rejects duplicate paths,
- bounds entry count, member size, total expanded size and compression ratio,
- writes extracted files through temporary files and atomic rename.

## Remaining gate before CAP can become a core LIVE source

Before the runtime CAP source may participate in a GREEN gate, the following
still has to be completed:

- parse every XML document in a status archive,
- reject the whole snapshot if required parsing completeness is not met,
- resolve update, replacement and cancellation chains across the snapshot,
- load and version the official DWD warning-area mapping for geocode-only areas,
- match Geiselhöring primarily by direct geometry and secondarily by official
  warning-cell geometry,
- classify only relevant weather events as hardware hazards,
- implement product-specific freshness and publication-delay limits,
- publish the completed CAP snapshot atomically,
- retain previously active alerts according to hazard-latching rules on failure.

Until those gates pass, DWD CAP remains `INITIALIZING`, `NOT_AVAILABLE`, or
`FAILED`, and hardware GREEN remains forbidden.
